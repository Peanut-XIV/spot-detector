Threshold settings

This parameter should be left in automatic for now, as the program handles this automatically, however, it could become helpful in the future. Since the colors are quantized, the pixels in the image can take only take a limited number of different values. The automatic setting takes that into acount. Nevertheless, here is how it works.

In order to detect the shape of the spots you wish to detect, spot-detector applies a binary filter on the images to process. This binary filter is applied on a range of thresholds, in order to acount for ambiant luminosity.
