Filtering by circularity

SimpleBlobDetector can also filter shapes by circularity to discriminate them. Circularity is a dimensionless value between 0 and 1 associated to a closed 2D shape. The closer the value is to 1, the rounder the shape is, with a perfect circle having a value of one.
