Detection parameters

Spot-detector is a point counting program that apply different criteria depending on the spot's color.

The counting is done using SimpleBlobDetector, an alogrithm from the Open-CV library, in order to count points.


The Open-CV logo

It does so by quantising the image, through a set binary thresholds. At each threshold, shape contours are detected. Then, each contour is associated to a tree node.

A node's parent is a node associated to the shape sharing the same location but detected at a lower threshold. That way, clusters of spots can be separated into invidual spots, as long as they are not overlapping. Finally, the nodes are filtered following shape descriptor criteria, and the remaining branches are counted. This process is repeated for each color category set by the user.

Here are the different shape descriptor criteria that you can configure (click on the setting fields for more information) :

  • Binary thresholds settings
  • Minimum distance between spots
  • Spot Area
  • Spot Circularity
  • Spot Convexity
  • Spot Inertia
